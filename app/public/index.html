Khoa Công nghệ Thông tin - Trường Đại học Công nghệ Thông tin & Truyền thông - Đại học Thái Nguyên.

Cổng Dịch Vụ Hệ Thống

  • Nginx HTTPS Proxy (Port 443)
  • phpMyAdmin Dashboard
  • Grafana Monitoring (Port 3001)
  • Prometheus Metrics (Port 9090)
  • cAdvisor Container Stats (Port 8080)
  • Loki Log Collector (Port 3100)

Tính Năng Bảo Mật (Hardening)

  • TLS 1.2 / TLS 1.3 Encryption
  • HTTP Strict Transport Security (HSTS)
  • X-Content-Type-Options: nosniff
  • X-Frame-Options: SAMEORIGIN
  • Promtail JSON Log Pipeline
